Security

Last Updated: December 6, 2024

At Synergy Bravo ERP, security is our top priority. We implement industry-leading security measures to protect your business data and ensure the confidentiality, integrity, and availability of our services.

SOC 2 Type II Certified ISO 27001 Compliant GDPR Compliant 99.9% Uptime SLA

1. Data Encryption

Encryption in Transit: All data transmitted between your device and our servers is encrypted using TLS 1.3 with 256-bit encryption.

Encryption at Rest: All stored data is encrypted using AES-256 encryption, including databases, backups, and file storage.

Key Management: Encryption keys are managed using industry-standard key management services with regular rotation policies.

2. Access Controls

  • Multi-Factor Authentication (MFA): Available for all users with support for authenticator apps and hardware tokens
  • Role-Based Access Control (RBAC): Granular permissions to control who can access specific data and features
  • Single Sign-On (SSO): Enterprise plans support SAML 2.0 and OAuth 2.0 for seamless integration
  • IP Whitelisting: Restrict access to your account from specific IP addresses
  • Session Management: Automatic timeout and forced logout for inactive sessions

3. Infrastructure Security

Cloud Infrastructure: Hosted on enterprise-grade cloud platforms with built-in security features:

  • Redundant data centers across multiple geographic regions
  • DDoS protection and web application firewall (WAF)
  • Network segmentation and isolation
  • Intrusion detection and prevention systems (IDS/IPS)

Continuous Monitoring: 24/7 security monitoring and alerting for suspicious activities

4. Application Security

  • Secure Development: Following OWASP guidelines and secure coding practices
  • Code Reviews: Mandatory security-focused code reviews before deployment
  • Vulnerability Scanning: Automated scanning for security vulnerabilities
  • Penetration Testing: Regular third-party security audits and penetration tests
  • Dependency Management: Continuous monitoring and patching of third-party libraries

5. Data Backup and Recovery

Automated Backups: Daily incremental backups and weekly full backups

Geo-Redundancy: Backups stored in multiple geographic locations

Recovery Testing: Regular disaster recovery drills to ensure data recoverability

Point-in-Time Recovery: Ability to restore data to any point within the last 30 days

Retention Policy: Backups retained for 90 days with option for extended retention on enterprise plans

6. Compliance and Certifications

We maintain compliance with major security and privacy standards:

  • SOC 2 Type II: Annual audits covering security, availability, and confidentiality
  • ISO 27001: Information security management system certification
  • GDPR: Full compliance with EU data protection regulations
  • HIPAA: Available for healthcare customers requiring PHI protection
  • PCI DSS: Level 1 compliance for payment card data handling

7. Employee Security

  • Background Checks: All employees undergo comprehensive background verification
  • Security Training: Mandatory annual security awareness training
  • Access Principles: Least privilege and need-to-know access policies
  • Confidentiality Agreements: All staff sign NDAs and security policies

8. Incident Response

24/7 Security Team: Dedicated security operations center monitoring for threats

Incident Response Plan: Documented procedures for identifying, containing, and resolving security incidents

Notification: We will notify affected customers within 72 hours of discovering a data breach

Forensics: Post-incident analysis to prevent future occurrences

9. Third-Party Security

We carefully vet all third-party vendors and service providers:

  • Security assessments before integration
  • Contractual security requirements
  • Regular security reviews of vendors
  • Vendor access monitoring and logging

10. Your Responsibilities

Security is a shared responsibility. We recommend you:

  • Use strong, unique passwords for your account
  • Enable multi-factor authentication
  • Keep your login credentials confidential
  • Regularly review user access and permissions
  • Report suspicious activity immediately
  • Keep your devices and software up to date

11. Transparency and Trust

Security Updates: We maintain a public security changelog for transparency

Bug Bounty Program: We reward security researchers who responsibly disclose vulnerabilities

Status Page: Real-time system status and incident history at status.synergyerp.com
